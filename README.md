# THE FREAKOFF: SHADOW WARS

A 2.5D arcade beat 'em up and versus fighter written in TypeScript with Vite. All graphics, voices, music and ambience are procedural; there are no asset files.

Five fighters (Slade, Freckles, White Lie, Fiddle Jay, Batman — no relation), six stages, and six modes: five-campaign story mode, 1P vs 2P, 1P vs CPU, 2v2 tag team, an arcade ladder with a shadow-boss finale, and a training room with hitboxes, frame data and a recording dummy. Four-button controls (attack, jump, block/parry, special) on keyboard, gamepad and touch, with input buffering.

The game lives in [`clash-game/`](clash-game/). See [`clash-game/README.md`](clash-game/README.md) for controls, modes and architecture.

```bash
cd clash-game
npm install
npm run dev    # http://localhost:47321
```
